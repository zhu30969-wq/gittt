# 评价与排序配方

本配方用于把多个方向、尺度和重要性不同的指标组合成评价分数、等级或排序。核心不是选 AHP/TOPSIS/熵权等标签，而是先固定评价对象、指标语义、归一化、权重来源、扰动范围和最终使用决策。

## 1. 结构签名

- 评价对象集合与每项指标的原始单位、效益/成本方向和缺失处理明确；
- 归一化函数与权重在查看最终名次前登记；
- 总分用于选择、分层或资源配置，名次变化会影响实际结论；
- 指标之间可能相关、重复计量或存在补偿性，需要可解释的聚合规则；
- 需要报告局部名次翻转与最大位移，而不只报告整体相关系数。

## 2. 不适用条件

- 题目本质有明确收益、成本和约束，可以直接优化，却用综合分替代目标；
- 指标方向、单位或缺失机制无法解释；
- 权重完全按希望得到的排名事后调整；
- 评价分数被称为真实概率、因果效应或行业预测；
- 方案间差异小于测量误差，却仍给出确定的逐名次结论。

## 3. 最简可运行基线

先用等权、清楚方向的线性加权作为基线，并保留各单项指标排序。若复杂评价方法不能在预先登记的扰动下比等权基线更稳定、也不能提供新的可解释结构，应保留简单基线。若总分将进入资源优化，另建直接目标模型核对综合分是否诱发负边际决策。

## 4. 标准数学表达

把原始指标 (x_{ij}) 按预先登记的方向和尺度变换为 (z_{ij}\in[0,1])，例如线性加权：

\[
s_i(w)=\sum_{j=1}^{p}w_jz_{ij},\qquad
w_j\ge0,\quad \sum_jw_j=1.
\]

对权重集合 (\mathcal W) 而非单一点进行稳定性分析。对每个扰动 (w'\in\mathcal W)，同时计算 Spearman 相关、发生顺序反转的对象对数和最大名次位移。相关系数接近 1 仍可能存在影响决策边界的局部翻转。

## 5. 数据与扰动预算

- 原始指标、清洗值、方向变换和归一化参数分别保存，避免数据更新后静默重标度；
- 权重基准、单项上下扰动、联合扰动范围与抽样种子在看排名前登记；
- 扰动范围依据测量误差、专家分歧或政策容忍度，而不是为获得稳定结果事后缩小；
- 对大量对象记录 top-k 交集、阈值边界翻转和最大位移；对少量对象可完整枚举权重网格；
- 若分数迁移到另一总体，另做逐指标漂移诊断，并明确其描述性性质。

## 6. 三条评价路线

| 路线 | 触发条件 | 交付证据 |
|---|---|---|
| 等权/规则评分 | 权重证据弱、可解释性优先 | 指标方向、归一化、单项与总分、完整扰动 |
| 有依据的加权聚合 | 权重来自专家、政策或数据且可追溯 | 权重来源、冲突处理、扰动与翻转报告 |
| 非补偿或分层规则 | 某指标低于阈值不能被其他高分抵消 | 门槛依据、边界样本、规则与加权基线对比 |

任何路线都要把“评价分数”与后续真实优化目标区分开；评分高不自动等于收益最大或风险最小。

## 7. 统一接口示例

可运行示例见 [evaluation_and_ranking.py](examples/evaluation_and_ranking.py)：

```powershell
python -X utf8 cumcm-modeling/references/recipes/examples/evaluation_and_ranking.py
```

示例先按预登记权重生成合成评分，再调用 `rank_stability` 同时报出 Spearman、翻转对象对数和最大位移；同时调用 `drift_diagnostic`，其返回值明确禁止因果表述。接口实现见 [predict_toolkit](../../assets/predict-toolkit/predict_toolkit/__init__.py)。

## 8. 必查失败模式

1. **高 Spearman 掩盖局部翻转（2020 C 真跑）**：一次权重扰动分析的 Spearman 中位数为 `0.9739`，仍不能说明关键边界对象没有交换名次；必须同时登记翻转对数、翻转对象和最大位移。
2. **看到结果后缩小扰动**：若原范围出现翻转就改成更窄范围，稳定性结论失去确认性。范围与种子应在生成最终排名前冻结。
3. **压力代理冒充行业因果预测（2020 C 真跑）**：Q3 只在附件内构造压力情景，它说明模型在该代理扰动下的响应，不代表识别了行业冲击原因或预测了真实干预效果。
4. **目标口径事后解释（2020 C 真跑）**：“固定总额必须全部投放”会让模型分配少量负边际贷款；这是目标与硬约束的建模选择，必须在求解前确认，不能结果出现后再把它解释成最优经营政策。
5. **指标重复计量**：两个高度相关指标分别赋权，会把同一机制计算两次。报告相关结构，并做删项或合并敏感性。
6. **归一化由极端值支配**：min-max 在新增异常对象后可能重排所有旧对象。冻结参照范围或比较稳健分位变换。

## 9. 独立验证

先构造已知权重变化必然交换一对对象的合成矩阵，验证翻转对数与最大位移精确；再构造严格分离的稳定矩阵验证不误报。对真实数据同时检查等权基线、删项、权重扰动、归一化方法和 top-k 边界。论文名次或单一相关系数不能作为 PASS 真值。

## 10. 解释边界

可以声明：在给定对象、指标方向、归一化、权重和扰动范围内的分数与稳定性；哪些对象对发生翻转；代理压力情景下的响应；描述性分布漂移。

不能声明：一个高 Spearman 保证所有名次稳定；综合分是概率或因果效应；附件内压力代理预测了行业冲击；固定投放总额下的数学最优自动等于允许少投时的经营最优。
